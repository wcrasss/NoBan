> ### Обход | NoBan
> NoBan — это аналог zapret с более большим кол-вом заблокированных сайтов, и более проще в использовании.
> > 

> [!WARNING]
>
> ### АНТИВИРУСЫ
> WinDivert может вызвать реакцию антивируса.
> WinDivert - это инструмент для перехвата и фильтрации трафика, необходимый для работы NoBan.
> Замена iptables и NFQUEUE в Linux, которых нет под Windows.
> Он может использоваться как хорошими, так и плохими программами, но сам по себе не является вирусом.
> Драйвер WinDivert64.sys подписан для возможности загрузки в 64-битное ядро Windows.
> Но антивирусы склонны относить подобное к классам повышенного риска или хакерским инструментам.
> В случае проблем используйте исключения или выключайте антивирус совсем.
>

## ⚙️ Использование

- Загрузите архив zip со [страницы последнего релиза](https://github.com/wcrasss/NoBan/releases/latest)
- Распакуйте содержимое архива
- Запустите нужный файл


  - `NoBan.bat` - запуск вручную со стратегией для обхода блокировок  
  - `service.bat` - функции:
  - `Проверить статус` - проверка статуса обхода и служб (стратегии на автозапуске и WinDivert)
  - `Выполнить диагностику` - диагностика на распространённые причины, по которым NoBan может не работать.  
  - `Проверить обновления` - проверка на обновления
  - `Переключить игровой фильтр` - переключение режима обхода для игр. В скобках указан текущий статус (включено/выключено).
  - `Переключить ipset` - переключение режима обхода сервисов из `ipset-all.txt`.
  
## ℹ️ Краткие описания файлов

  - `NoBan.bat` - Запуск стратегии вручную. [A,B,C,D,E,F,G,H]

  - `service.bat` - Установка в автозапуск и другие функции:

  - `[1] Проверить статус` - Проверка статуса обхода и служб
  - `[2] Выполнить диагностику` -диагностика на распространённые причины, по которым NoBan может не работать.
      - В конце можно очистить кэш Discord, что может помочь, если он неожиданно перестал работать.
  - `[3] Проверить обновления` - Проверка на обновления.
  - `[4] Переключить игровой фильтр` - Переключение режима обхода для игр. В скобках указан текущий статус (включено/выключено).
  - `[5] Переключить ipset` - Переключение режима обхода сервисов из ipset-all.txt.
      - В скобках указан текущий статус:
      - "none" - никакие айпи не попадают под проверку,
      - "loaded" - айпи проверяется на вхождение в список,
      - "any" - любой айпи попадает под фильтр.
  - `[6] Установить автозагрузку`
      - Установить автозагрузку любого профиля обхода.
  - `[7] Убрать автозагрузку / Остановить NoBan` 
      - Убрать NoBan из автозагрузки.
  - `[8] Проверка работоспособности доменов`
      - Проверка списка доменов через определённые профиля. Вы можете добавить файл(ы) с доменами, и проверить их.
  - `[9] Проверка доменов (Простая)`
      - Простая проверка доменов. (Это тестовая функция, возможно в новой версии она будет удалена!)
  - `[10] Профессиональная разблокировка`
       - Профессиональная разблокировка сайтов/приложений!

## ℹ️ Автозагрузка (new)

  - `САМОЕ ГЛАВНОЕ НЕ УДАЛЯЙТЕ ПАПКУ!`
  - В папке autoload находятся все доступные профиля обхода.
  - В service.bat вы можете выбрать профиль, который хотите добавить в автозагрузку.
  - При включении ПК он у вас автоматически запустится!
  - Не волнуйтесь, если он не показывается на панели задач, он РАБОТАЕТ!

## 📖 Добавление адресов прочих заблокированных ресурсов

Список адресов для обхода можно расширить, добавляя их в:
- `list-noban.txt` - для доменов (поддомены автоматически учитываются)
- `list-exclude.txt` - для исключения доменов
- `ipset-all.txt` - для IP и подсетей
- `ipset-exclude.txt` - для исключения IP и подсетей

## 📌 Распространенные вопросы и проблемы

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Откройте `service.bat`
- Выберите `"Выполнить диагностику"`
- После диагностики вам предложат очистить кеш Discord, согласитесь, написав `"да"`

### NoBan не работает / перестал работать

- Стратегии со временем могут переставать работать.
- Определенная стратегия может работать какое-то время, но со временем она может переставать работать из-за обнаружения.
- В репозитории представлены множество различных стратегий для обхода.
